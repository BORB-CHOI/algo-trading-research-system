# ATS v4.0 정체성 재정의 — 구현 계획

> **작업자에게:** 이 계획은 `superpowers:subagent-driven-development` 또는
> `superpowers:executing-plans`로 과제 단위로 실행한다. 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 지침서 v3.8의 정체성을 "가설 검증 + 사람 승인 후 자동 실행 + 알파 감시"로 다시 쓰고,
검증 대기 가설을 별도 폴더로 옮기며, 백테스트의 구멍 3건을 메운다. **기존 코드는 지우지 않는다.**

**접근:** 문서를 먼저 확정하고(과제 1~5) 코드를 그 뒤에 손댄다(과제 6~10). 코드 과제는
전부 **기존 파일에 추가**하는 방식이며, 전략 로직·체결 규칙·UI는 건드리지 않는다.

**⚠️ 역할 경계 (오너 지적 2026-08-16 — 이 계획 초안이 어겼던 것):**
AI가 하는 일은 **코딩 · 글 해석 · 시키면 계산 돌리기** 셋뿐이다. 어떤 조건으로 종목을
거를지, 어떤 임계값을 쓸지, 어떤 순서로 검증할지, 어떤 구간을 볼지는 **오너가 화면에서
정한다.** 이 계획의 모든 코드 과제는 "오너가 화면에서 고를 수 있게 만드는 일"이다.
설계서 §2.1 참조.

**기술 스택:** Python 3.12 · pandas · FastAPI · pytest · SQLite(보관함) · React/Vite(웹, 이번엔 손 안 댐)

**명세서:** [docs/superpowers/specs/2026-08-16-ats-v4-design.md](../specs/2026-08-16-ats-v4-design.md)

## 전역 제약 (모든 과제에 적용)

- **한국어로 쓴다.** 코드 주석·문서·커밋 메시지 전부. 화면 라벨뿐 아니라 전부 해당.
- **쉬운 말로 쓴다.** 영어 용어(leg·swing·pivot·drawdown·look-ahead)와 지어낸 용어를 그대로
  쓰지 않는다. 꼭 필요하면 쉬운 말을 먼저 쓰고 괄호 안에만 원어. (CLAUDE.md)
  - 하락 레그 ❌ → "고점 찍고 내려온 구간" ⭕
  - 룩어헤드 ❌ → "미래 데이터 훔쳐보기" ⭕
  - point-in-time universe ❌ → "당시 기준 종목 목록" ⭕
  - survivorship bias ❌ → "살아남은 것만 보는 착시" ⭕
- **삭제하지 않는다.** 문서는 옮기고(`docs/archive/`, `docs/hypotheses/`), 코드는 추가만 한다.
  큰 삭제·구조 변경이 필요해 보이면 **멈추고 오너에게 묻는다.**
- **모든 정량 임계값은 임시값(placeholder)이다.** 하드코딩 ❌, 설정으로 주입.
- **테스트 618개가 계속 통과해야 한다.** 실행: `.venv/Scripts/python.exe -m pytest tests/ -q`
- **커밋 형식:** `<type>: <설명>` (feat/fix/docs/refactor/test/chore). 과제마다 커밋.
- **ADR을 뒤집을 때 지우지 않는다.** 상태만 `대체됨`으로 바꾸고 새 ADR을 쓴다.

```markdown
여기 있는 것은 **오너가 화면에서 조건을 만들 때 꺼내 쓰는 원재료**다.

## 왜 따로 두는가

지침서(`../PROJECT_GUIDELINES.md`)는 **확정된 원칙**만 담는다. 검증 안 된 주장이 원칙과

## 항목 서식

### (한 줄 제목)

- **출처 발언:** 누가 언제 무슨 말을 했나 (원문 인용)
- **쉬운 말:** 무슨 뜻인지 중학생도 알아듣게
- **전략 계층:** 종목 선정 / 시장 상황 / 전략군 / 모양 / 진입 / 비중 / 청산 / 위험 / 실행
- **필요 데이터:** 무엇이 있어야 하나 + 지금 있나
- **화면에서 고를 수 있나:** ⭕ (조건 이름) / ❌ (아직 없음 — 만들어야 함)
- **주의:** 그때 알 수 있었던 정보만 쓰려면 무엇을 조심해야 하나

**넣지 않는 것: 우선순위 · 검증 상태 · 번호(H-NNN) · 실험 조합표.**
무엇을 먼저 볼지, 어떻게 조합할지는 **오너가 화면에서 정한다.**
```

```python
# ── 검사 구간 (오너 결정 2026-08-16) ────────────────────────
#
# **코드가 구간을 정하지 않는다.** 화면에서 고른 날짜가 그대로 검사 구간이다.
# 오너: "2007~ 나누지 않고 전체." 연습/검증/시험 3분할은 쓰지 않는다.

DEFAULT_START = "2007-01-01"


def resolve_period(
    start: str | None, end: str | None, *, latest: pd.Timestamp | None = None
) -> tuple[pd.Timestamp, pd.Timestamp]:
    """화면이 준 날짜를 그대로 쓴다. 안 주면 2007-01-01 ~ 최신 거래일."""
    s = pd.Timestamp(start) if start else pd.Timestamp(DEFAULT_START)
    e = pd.Timestamp(end) if end else (latest if latest is not None else pd.Timestamp.today().normalize())
    if s > e:
        raise ValueError(f"시작하는 날({s.date()})이 끝나는 날({e.date()})보다 뒤입니다.")
    return s, e
```

```python
def cond_marcap_rank_pct(hist: HistPanel, base: pd.DataFrame, p: dict) -> pd.Series:
    """그날 시가총액 **상위 N%**.

    금액(5,000억 등)으로 걸면 시대마다 뜻이 달라진다 — 실측: 시총 5,000억이 2007년엔
    상위 10.7%, 2025년엔 상위 18.0%(시장 전체가 3.8배 커졌다). 순위로 걸면 그날 기준으로
    자동으로 맞춰진다. **금액으로 걸지 순위로 걸지는 화면에서 고른다.**
    """
    top = float(p.get("top_pct") or 0)
    s = pd.to_numeric(base["Marcap"], errors="coerce")
    if top <= 0 or s.notna().sum() == 0:
        return _none(base)
    cut = s.quantile(1.0 - top / 100.0)
    return s.notna() & (s >= cut)


def cond_amount_rank(hist: HistPanel, base: pd.DataFrame, p: dict) -> pd.Series:
    """그날 거래대금 **상위 N위**."""
    n = int(p.get("top_n") or 0)
    s = pd.to_numeric(base["Amount"], errors="coerce")
    if n <= 0 or s.notna().sum() == 0:
        return _none(base)
    keep = s.dropna().nlargest(n).index
    return base.index.isin(keep) & s.notna()
```

```python
def near_miss_ticks(low: float, target: float, tick: float) -> int:
    """저가가 목표가보다 **몇 호가 더** 내려갔는지.

    0 = 딱 닿기만 했다 → 실제로는 내 주문 앞 물량이 안 빠져 못 살 수 있다.

    호가 오프셋 값을 조절하며 확인할 때 쓰기 위한 것이다.
    """

        return 0
    return int((target - low) / tick)
```

```python
def save_fills(run_id: int, rows: list[dict], *, db: Path | None = None) -> None:
    """체결 한 줄씩 남긴다 — 두 실험을 줄 단위로 비교하기 위한 것."""
    if not rows:
        return
    with _connect(db) as conn:
        conn.executemany(
            f"INSERT INTO fills (run_id, {', '.join(_FILL_COLS)}) "
            f"VALUES (?, {', '.join('?' * len(_FILL_COLS))})",
            [(run_id, *(r.get(c) for c in _FILL_COLS)) for r in rows],
        )


def load_fills(run_id: int, *, db: Path | None = None) -> list[dict]:
    """한 실험의 체결 전부."""
    with _connect(db) as conn:
        cur = conn.execute(
            f"SELECT {', '.join(_FILL_COLS)} FROM fills WHERE run_id = ? ORDER BY date, code",
            (run_id,),
        )
        return [dict(zip(_FILL_COLS, row, strict=True)) for row in cur.fetchall()]
```

```python
"""전략에 데이터를 건네는 창구 하나.

전략이 `data/derived/adjusted/{code}.parquet` 같은 **파일 경로를 직접 알면**, 데이터
위치나 형식이 바뀔 때마다 전략을 다 고쳐야 한다 (미션 문서 §19-4).

`as_of` 를 주면 **그날 뒤 행을 잘라서** 준다. "그때 알 수 있었던 정보만" 원칙을
전략이 아니라 창구가 강제한다 — 전략마다 따로 지키면 언젠가 하나가 빠진다.

⚠️ **수급에는 망한 회사가 없다.** 실측 2026-08-16: 2010년엔 있었고 2025년엔 없는 종목
595개 중 수급 파일이 있는 것은 0개(일봉은 595개 전부 있다). KIS API 가 상장 종목만 주기
때문이다. 수급 조건으로 과거를 검사하면 망한 회사가 표본에서 빠져 결과가 부풀려진다 —
`supply_coverage()` 로 얼마나 빠졌는지 알 수 있다.
"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import pandas as pd

DEFAULT_ROOT = Path("data/derived")


@dataclass(frozen=True)
class DataProvider:
    """읽기 창구. 값을 바꾸지 않는다 — 늘 새 표를 돌려준다."""

    root: Path = DEFAULT_ROOT

    def daily(self, code: str, *, as_of: pd.Timestamp | None = None) -> pd.DataFrame:
        """한 종목의 수정주가 일봉. `as_of` 이후 행은 잘라 낸다."""
        path = self.root / "adjusted" / f"{str(code).zfill(6)}.parquet"
        if not path.exists():
            raise FileNotFoundError(f"{code} 의 일봉이 없습니다 — {path}")
        return self._cut(pd.read_parquet(path), as_of)

    def supply(self, code: str, *, as_of: pd.Timestamp | None = None) -> pd.DataFrame:
        """한 종목의 외인·기관·개인 수급 (ADR-0012). 상폐 종목은 없다."""
        path = self.root / "supply" / f"{str(code).zfill(6)}.parquet"
        if not path.exists():
            raise FileNotFoundError(
                f"{code} 의 수급이 없습니다 — {path} "
                f"(상장폐지 종목은 수급을 받을 수 없습니다)"
            )
        return self._cut(pd.read_parquet(path), as_of)

    def panel(self, y0: int, y1: int) -> pd.DataFrame:
        """전 종목 × 날짜 표 (marcap). 정본 로더를 그대로 부른다."""
        from src.layer1_data.marcap_loader import load_years

        return load_years(y0, y1)

    def supply_coverage(self) -> dict[str, int]:
        """수급이 몇 종목이나 빠졌는지 — 화면 경고에 쓴다."""
        adj = {p.stem for p in (self.root / "adjusted").glob("*.parquet")}
        sup = {p.stem for p in (self.root / "supply").glob("*.parquet")}
        return {"일봉": len(adj), "수급": len(sup), "수급_없는_종목": len(adj - sup)}

    @staticmethod
    def _cut(df: pd.DataFrame, as_of: pd.Timestamp | None) -> pd.DataFrame:
        if as_of is None:
            return df.reset_index(drop=True)
        return df.loc[df["Date"] <= as_of].reset_index(drop=True)
```
