# ATS v4.0 정체성 재정의 — 구현 계획

> **작업자에게:** 이 계획은 `superpowers:subagent-driven-development` 또는
> `superpowers:executing-plans`로 과제 단위로 실행한다. 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 지침서 v3.8의 정체성을 "가설 검증 + 사람 승인 후 자동 실행 + 알파 감시"로 다시 쓰고,
검증 대기 가설을 별도 폴더로 옮기며, 백테스트의 구멍 3건을 메운다. **기존 코드는 지우지 않는다.**

**접근:** 문서를 먼저 확정하고(과제 1~5) 코드를 그 뒤에 손댄다(과제 6~10). 문서가 코드의
구간 경계·용어를 인용하므로 순서가 뒤집히면 두 번 고치게 된다. 코드 과제는 전부
**기존 파일에 추가**하는 방식이며, 전략 로직·체결 규칙·UI는 건드리지 않는다.

**기술 스택:** Python 3.12 · pandas · FastAPI · pytest · SQLite(보관함) · React/Vite(웹, 이번엔 손 안 댐)

**명세서:** [docs/superpowers/specs/2026-08-16-ats-v4-design.md](../specs/2026-08-16-ats-v4-design.md)

---

## 전역 제약 (모든 과제에 적용)

- **한국어로 쓴다.** 코드 주석·문서·커밋 메시지 전부. 화면 라벨뿐 아니라 전부 해당.
- **쉬운 말로 쓴다.** 영어 용어(leg·swing·pivot·drawdown·look-ahead)와 지어낸 용어를 그대로
  쓰지 않는다. 꼭 필요하면 쉬운 말을 먼저 쓰고 괄호 안에만 원어. (CLAUDE.md)
  - 하락 레그 ❌ → "고점 찍고 내려온 구간" ⭕
  - 룩어헤드 ❌ → "미래 데이터 훔쳐보기" ⭕
  - point-in-time universe ❌ → "당시 기준 종목 목록" ⭕
  - survivorship bias ❌ → "살아남은 것만 보는 착시" ⭕
- **삭제하지 않는다.** 문서는 옮기고(`docs/archive/`, `docs/hypotheses/`), 코드는 추가만 한다.
  큰 삭제·구조 변경이 필요해 보이면 **멈추고 오너에게 묻는다.**
- **모든 정량 임계값은 임시값(placeholder)이다.** 하드코딩 ❌, 설정으로 주입.
- **테스트 618개가 계속 통과해야 한다.** 실행: `.venv/Scripts/python.exe -m pytest tests/ -q`
- **커밋 형식:** `<type>: <설명>` (feat/fix/docs/refactor/test/chore). 과제마다 커밋.
- **ADR을 뒤집을 때 지우지 않는다.** 상태만 `대체됨`으로 바꾸고 새 ADR을 쓴다.

## 카드 서식

### H-NNN · (한 줄 제목)

- **출처 발언:** 누가 언제 무슨 말을 했나 (원문 인용)
- **쉬운 말 가설:** 검증할 내용을 중학생도 알아듣게
- **전략 계층:** 종목 선정 / 시장 상황 / 전략군 / 모양 / 진입 / 비중 / 청산 / 위험 / 실행
- **필요 데이터:** 무엇이 있어야 검증되나 + 지금 있나
- **계산 시점:** 그때 알 수 있었던 정보만 쓰려면 무엇을 조심해야 하나
- **지금 검증 가능?** ⭕ / ❌ (없는 데이터 명시)
- **검증 상태:** 미검증 / 검증 중 / 통과 / 탈락 / 보류(표본 부족)
- **사전 우선순위:** 높음 / 중간 / 낮음 — **이건 기대일 뿐 근거가 아니다**

## 채택 규칙

- 표본 30건 미만이면 통계를 믿지 않는다.
- 단순히 합쳐서 좋아졌다고 채택 ❌. **하나씩 빼 보고** 그 조건이 없을 때 얼마나 나빠지는지 본다.
- 승률과 IC(순위 상관)는 다른 지표다. 둘 다 본다.
- 통과한 가설도 실전에서 힘이 약해지면 다시 내려온다.

## 비교 실험 (미션 문서 §15)

같은 진입·청산 규칙에 종목 선정만 바꿔서 성적을 비교한다. 이게 "어떤 조건이 진짜

### H-001 · 시가총액 5,000억 이상이면 눌림매매가 더 잘 통하는가

- **출처 발언:** 미션 문서 §15 — "규모·유동성·작전성 종목 회피를 통제하기 위한 후보 조건"
- **쉬운 말 가설:** 회사가 어느 정도 크면 이상한 움직임이 적어서 규칙이 더 잘 맞는다
- **전략 계층:** 종목 선정
- **필요 데이터:** 일별 시가총액 (marcap, 있음 ⭕)
- **계산 시점:** **그날 시총**을 쓴다. 오늘 시총으로 과거 종목을 고르면 안 된다
- **지금 검증 가능?** ⭕
- **검증 상태:** 미검증
- **사전 우선순위:** 높음
- **주의:** 5,000억은 임시값이다. v3.8 §4.2는 1,000억~3조를 적었다 — **둘 다 실험 대상**이지
  어느 쪽도 확정이 아니다.
```

# ── 세 구간 나누기 (지침서 §4.3) ────────────────────────────
#
# 시험 구간을 **미래**로 둔다 (2026-08-16 재절단). 옛 경계(시험 = 2025)는 「전 구간」 검사가

# 2019-01-01~2026-08-10). 아직 오지 않은 날짜는 그럴 수가 없다.
SPLITS: dict[str, tuple[str, str]] = {
    "train": ("2017-01-01", "2023-12-31"),     # 연습 — 마음껏 값을 바꿔 본다
    "validate": ("2024-01-01", "2026-08-31"),  # 검증 — 골라낸 것을 확인한다
    "test": ("2026-09-01", "2099-12-31"),      # 시험 — 딱 한 번
}


def guard_period(
    start: pd.Timestamp, end: pd.Timestamp, *, i_know_test_is_once: bool = False
) -> None:
    """임의 구간이 시험 구간을 넘보면 막는다.

    `slice_split` 은 이름으로 부를 때만 막아 준다. 「전 구간」 검사처럼 날짜를 직접 받는
    길에는 가드가 없었다 — 그래서 같은 판정을 여기 하나 더 둔다.
    """
    if i_know_test_is_once:
        return
    t0, t1 = (pd.Timestamp(d) for d in SPLITS["test"])
    if start <= t1 and end >= t0:
        raise ValueError(
            f"시험 구간({t0.date()}~)과 겹칩니다. 시험은 단 1회만 씁니다(§4.3) — "
            f"보고 값을 고치면 그 순간 연습 구간이 됩니다. "
            f"정말 최종 평가라면 i_know_test_is_once=True 를 명시하세요."
        )
```

def save_fills(run_id: int, rows: list[dict], *, db: Path | None = None) -> None:
    """체결 한 줄씩 남긴다 — 실험을 나중에 줄 단위로 비교하기 위한 것."""
    if not rows:
        return
    with _connect(db) as conn:
        conn.executemany(
            f"INSERT INTO fills (run_id, {', '.join(_FILL_COLS)}) "
            f"VALUES (?, {', '.join('?' * len(_FILL_COLS))})",
            [(run_id, *(r.get(c) for c in _FILL_COLS)) for r in rows],
        )


def load_fills(run_id: int, *, db: Path | None = None) -> list[dict]:
    """한 실험의 체결 전부."""
    with _connect(db) as conn:
        cur = conn.execute(
            f"SELECT {', '.join(_FILL_COLS)} FROM fills WHERE run_id = ? "
            f"ORDER BY date, code",
            (run_id,),
        )
        return [dict(zip(_FILL_COLS, row, strict=True)) for row in cur.fetchall()]

"""전략에 데이터를 건네는 창구 하나.

전략이 `data/derived/adjusted/{code}.parquet` 같은 **파일 경로를 직접 알면**, 데이터
위치나 형식이 바뀔 때마다 전략을 다 고쳐야 한다. 그래서 창구를 하나 둔다
(미션 문서 §19-4 — 전략 → 데이터 창구 → 실제 데이터).

`as_of` 를 주면 **그날 뒤 행을 잘라서** 준다. "그때 알 수 있었던 정보만" 원칙을
전략이 아니라 창구가 강제한다 — 전략마다 따로 지키면 언젠가 하나가 빠진다.
"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import pandas as pd

DEFAULT_ROOT = Path("data/derived")


@dataclass(frozen=True)
class DataProvider:
    """읽기 창구. 값을 바꾸지 않는다 — 늘 새 표를 돌려준다."""

    root: Path = DEFAULT_ROOT

    def daily(self, code: str, *, as_of: pd.Timestamp | None = None) -> pd.DataFrame:
        """한 종목의 수정주가 일봉. `as_of` 이후 행은 잘라 낸다."""
        path = self.root / "adjusted" / f"{str(code).zfill(6)}.parquet"
        if not path.exists():
            raise FileNotFoundError(f"{code} 의 일봉이 없습니다 — {path}")
        df = pd.read_parquet(path)
        return self._cut(df, as_of)

    def supply(self, code: str, *, as_of: pd.Timestamp | None = None) -> pd.DataFrame:
        """한 종목의 외인·기관·개인 수급 (ADR-0012)."""
        path = self.root / "supply" / f"{str(code).zfill(6)}.parquet"
        if not path.exists():
            raise FileNotFoundError(f"{code} 의 수급이 없습니다 — {path}")
        return self._cut(pd.read_parquet(path), as_of)

    def panel(self, y0: int, y1: int) -> pd.DataFrame:
        """전 종목 × 날짜 표 (marcap). 정본 로더를 그대로 부른다."""
        from src.layer1_data.marcap_loader import load_years

        return load_years(y0, y1)

    @staticmethod
    def _cut(df: pd.DataFrame, as_of: pd.Timestamp | None) -> pd.DataFrame:
        if as_of is None:
            return df.reset_index(drop=True)
        return df.loc[df["Date"] <= as_of].reset_index(drop=True)
```

"""

from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass

import pandas as pd

# 억 단위로 사람이 읽게 — 5e11 = 5,000억
_EOK = 1e8


@dataclass(frozen=True)
class SelectionRule:
    """그날 고를 종목을 정하는 규칙 하나."""

    name: str
    _pick: Callable[[pd.DataFrame, pd.Timestamp], list[str]]
    _describe: str

    def pick(self, panel: pd.DataFrame, as_of: pd.Timestamp) -> list[str]:
        """그날 조건에 걸린 종목 코드. **그날 행만** 본다."""
        today = panel.loc[panel["Date"] == as_of]
        return self._pick(today, as_of)

    def describe(self) -> str:
        """화면·문서에 쓸 사람 말 설명."""
        return self._describe

    @classmethod
    def all_stocks(cls) -> SelectionRule:
        """기준선 — 아무 조건 없이 전부. 다른 규칙은 이것보다 나아야 의미가 있다."""
        return cls(
            name="전체 종목",
            _pick=lambda df, _: sorted(str(c) for c in df["Code"]),
            _describe="조건 없이 그날 거래되던 종목 전부 (비교 기준선)",
        )

    @classmethod
    def by_marcap(cls, name: str, *, min_marcap: float) -> SelectionRule:
        """시가총액 하한. `min_marcap` 은 원 단위 (5e11 = 5,000억)."""
        return cls(
            name=name,
            _pick=lambda df, _: sorted(
                str(c) for c in df.loc[df["Marcap"] >= min_marcap, "Code"]
            ),
            _describe=f"그날 시가총액이 {min_marcap / _EOK:,.0f}억 이상인 종목",
        )


def run_experiments(
    rules: list[SelectionRule], panel: pd.DataFrame, as_of: pd.Timestamp
) -> dict[str, list[str]]:
    """여러 선정 규칙을 나란히 돌려 결과를 견준다 (실험 A~G)."""
    return {r.name: r.pick(panel, as_of) for r in rules}
```
