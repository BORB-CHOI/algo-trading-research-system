## Layer 4 — 실행/백테스트

- 거래비용 정액률 다단계 (ADR-0004, 3690d66)
- 백테스트 엔진 골격 — 신호(t)→t+1 시가 체결, 거래정지 연기, 3분할 가드, N<30 플래그 (ADR-0007, d17271b)
- 슬리피지 제곱근 충격 모델 + 유동성 하한 공식 ADV≥Q·(k/s)² (ADR-0004 갱신, 355d593)
- 멀티종목 러너 — 조건검색식으로 유니버스 선별 → 전략 신호 → 종목별 체결 → 집계 (ADR-0007/0009)
  - v1 한계 명시: 유니버스 선별 1회(주기 리밸런스 없음), cum_net_return 은 순차 복리(포트폴리오 자본곡선 아님)
- KIS 브로커 어댑터 — 토큰 발급·캐싱, rt_cd 실패 판정, HTS조회상위20 (ADR-0010, 51c91a1)
  - **조회 전용**. 주문 전송·hashkey 없음 — 모의투자 확보 후 새 ADR (CLAUDE.md 단계 6)
  - 조회상위는 "지금 이 순간"만 준다 → point-in-time 재현 불가, **백테스트 ❌**. 쓰려면 지금부터 시계열 축적
  - 시장구분 코드 확정 — `J`=유가증권(ETF 포함), `Q`=코스닥(글로벌 포함). KONEX 는 미관측 (BORB-47)
  - 호출 제한 미대응 — 프로브 연타만으로 `EGW00201 초당 거래건수 초과`. 백필 전에 스로틀 필요
