# ADR-0008: 케이스 검사기 HTS형 멀티뷰 UI

- **상태:** 수락
- **날짜:** 2026-07-24
- **관련:** BORB-40, ADR-0005(웹 스택), CLAUDE.md·오너 지시(기존 바퀴 재사용 — "유명·검증된 오픈소스 우선")

## 맥락 (Context)

단일 화면(사이드바+차트)으로는 오너의 실사용 흐름(HTS 식 멀티창 — 차트·조건검색·관심종목·
수급·뉴스 동시 보기)을 못 담는다. 오너 요구: 패널을 ① 한 화면 멀티뷰(드래그앤드롭+리사이즈)
② 상단 탭 ③ 플로팅 창 ④ 브라우저 새창 네 형태로 다룰 수 있어야 한다.

## 검토한 선택지 (Options)

- **OpenTerminalUI 통째 도입** — 기능은 가장 많지만 무명(55★ 개인 프로젝트), 로컬 설치 실패,
  데이터 레이어 대개조 필요 → 탈락.
- **openalgo-heatmap** — finviz 형 React 트리맵. 기능은 맞지만 무명 → ECharts 로 대체.
- **finviz 임베드** — `X-Frame-Options: SAMEORIGIN` 으로 iframe 차단(실측). 원본은 새창 폴백만
  가능. 데이터 스크래퍼(mariostoev/finviz)로 미국 맵을 재현하는 안은 오너 결정으로 **보류**.
- **조립형 (선택)** — 아래.

## 결정 (Decision)

기존 스택(FastAPI + Vite/React + KLineChart Pro) 위에 **유명·검증된 라이브러리 조립**:

1. **창 관리 = dockview** (dockview-react 7.x). 도킹 라이브러리 중 다운로드 1위(주 11.6만, 3.3k★).
   탭·분할·드래그앤드롭·리사이즈·플로팅 그룹·브라우저 팝아웃 새창 전부 내장 — 요구 4형태 충족.
2. **시장맵 = Apache ECharts treemap** (Apache 재단). marcap 데이터로 finviz 형 맵을 네이티브
   렌더(`/api/heatmap`). 시총=타일 크기, 등락=한국식 빨강/파랑.
3. **패널 구성**: 차트(KLineChart Pro 재사용)·조건검색·전략 오버레이·시장맵·관심종목(테마)·
   뉴스(자리)·Finviz(새창 폴백). 패널 간 종목 선택은 경량 이벤트 버스로 전파.
4. **레이아웃 저장/복원**: dockview `toJSON/fromJSON` + localStorage. 초기화 버튼 제공.
5. HTS 화면을 **기본 페이지로 승격**, 기존 단일 화면(App.tsx)은 제거(기능은 패널로 이식됨).

## 결과 (Consequences)

- 창 관리 코드를 직접 유지보수하지 않는다. dockview 메이저 업그레이드 시 마이그레이션 비용은 감수.
- marcap 에 업종 분류가 없어 시장맵은 시장(KOSPI/KOSDAQ) 그룹까지만 — 업종 중첩은 업종
  데이터 소스 확보 후(별도 이슈).
- 관심종목은 localStorage 데모 수준 — 서버 저장(파일/SQLite)으로 승격은 후속.
- 뉴스 패널은 자리만 — 소스는 Backtest Phase 2 때(지침서).

## 미해결 (Open questions)

1. 업종(섹터) 분류 데이터 소스 → 시장맵 업종 중첩.
2. 관심종목 서버 저장 + 수급 패널(BORB-33 계열 확정 후).
