# ADR-0008: 케이스 검사기 HTS형 멀티뷰 UI

- **상태:** 수락
- **날짜:** 2026-07-24
- **관련:** BORB-40, ADR-0005(웹 스택), CLAUDE.md·오너 지시(기존 바퀴 재사용 — "유명·검증된 오픈소스 우선")

## 맥락 (Context)

단일 화면(사이드바+차트)으로는 오너의 실사용 흐름(HTS 식 멀티창 — 차트·조건검색·관심종목·
수급·뉴스 동시 보기)을 못 담는다. 오너 요구: 패널을 ① 한 화면 멀티뷰(드래그앤드롭+리사이즈)
② 상단 탭 ③ 플로팅 창 ④ 브라우저 새창 네 형태로 다룰 수 있어야 한다.

## 검토한 선택지 (Options)

- **OpenTerminalUI 통째 도입** — 기능은 가장 많지만 무명(55★ 개인 프로젝트), 로컬 설치 실패,
  데이터 레이어 대개조 필요 → 탈락.
- **openalgo-heatmap** — finviz 형 React 트리맵. 기능은 맞지만 무명 → ECharts 로 대체.
- **finviz 임베드** — `X-Frame-Options: SAMEORIGIN` 으로 iframe 차단(실측). 원본은 새창 폴백만
  가능. 데이터 스크래퍼(mariostoev/finviz)로 미국 맵을 재현하는 안은 오너 결정으로 **보류**.
- **조립형 (선택)** — 아래.

## 결정 (Decision)

기존 스택(FastAPI + Vite/React + KLineChart Pro) 위에 **유명·검증된 라이브러리 조립**:

1. **창 관리 = dockview** (dockview-react 7.x). 도킹 라이브러리 중 다운로드 1위(주 11.6만, 3.3k★).
   탭·분할·드래그앤드롭·리사이즈·플로팅 그룹·브라우저 팝아웃 새창 전부 내장 — 요구 4형태 충족.
2. **시장맵 = Apache ECharts treemap** (Apache 재단). marcap 데이터로 finviz 형 맵을 네이티브
   렌더(`/api/heatmap`). 시총=타일 크기, 등락=한국식 빨강/파랑.
3. **패널 구성**: 차트(KLineChart Pro 재사용)·조건검색·전략 오버레이·시장맵·관심종목(테마)·
   뉴스(자리)·Finviz(새창 폴백). 패널 간 종목 선택은 경량 이벤트 버스로 전파.
4. **레이아웃 저장/복원**: dockview `toJSON/fromJSON` + localStorage. 초기화 버튼 제공.
5. HTS 화면을 **기본 페이지로 승격**, 기존 단일 화면(App.tsx)은 제거(기능은 패널로 이식됨).

## 결과 (Consequences)

- 창 관리 코드를 직접 유지보수하지 않는다. dockview 메이저 업그레이드 시 마이그레이션 비용은 감수.
- marcap 에 업종 분류가 없어 시장맵은 시장(KOSPI/KOSDAQ) 그룹까지만 — 업종 중첩은 업종
  데이터 소스 확보 후(별도 이슈).
- 관심종목은 localStorage 데모 수준 — 서버 저장(파일/SQLite)으로 승격은 후속.
- 뉴스 패널은 자리만 — 소스는 Backtest Phase 2 때(지침서).

## 미해결 (Open questions)

1. 업종(섹터) 분류 데이터 소스 → 시장맵 업종 중첩.
2. 관심종목 서버 저장 + 수급 패널(BORB-33 계열 확정 후).

## 개정 2026-08-03 — 소프트 UI 전면 적용 + 헤더 재구성 (오너 지시)

계기: 오너가 KIS 앱 화면 4장을 제시하며 "이미지 화면대로, 전체 디자인 느낌도 이미지처럼
부드러운 UI로", "상단 헤더 구성도 HTS/MTS에 적절하게 재구성", "시각적인 차트를 넣어라"고 지시.

1. **디자인 토큰 교체** — 고밀도 회색 톤 → 소프트 톤. 카드 반지름 14px·컨트롤 10px·알약 999px,
   그림자 2단계, 컨트롤 높이 24→32px, 본문 12→13px. 액센트는 KIS 앱과 같은 초록 계열
   (`#7cb342`). 등락색은 한국식 유지(상승 빨강 `#f04452` / 하락 파랑 `#3182f6`).
2. **헤더 2행 구조** (기존 1행 버튼 나열 폐기)
   - 1행: 브랜드 · 통합 종목검색(디바운스 200ms, Enter=첫 결과) · **지수 티커 스트립**
     (코스피·코스닥·나스닥·S&P·나스닥선물·달러원·VIX + 각 미니차트) · 시세 기준일 배지
   - 2행: 메뉴바 — 클릭 시 **이미 열린 패널이면 이동, 없으면 새로 연다**(Shift=항상 새 탭).
     활성 패널은 dockview `onDidActivePanelChange` 로 추적해 강조.
3. **미니차트(스파크라인)** — 의존성 추가 없이 SVG 컴포넌트 자체 구현(선+그라데이션 면).
   서버가 최근 30 종가를 내려준다: `/api/market` 의 `spark`, `/api/quotes?spark=true`.
   표시 전용이라 분할 보정을 하지 않는다(정본 캔들은 `/api/candles` 가 ADR-0006 으로 보정).
4. **시세포착 감시 목록** — KIS "시세포착 주문" 화면을 그대로 옮김. 매수감시/매도감시/주문내역
   탭, 좌측 컬러바 행, 감시/중지 토글, 우하단 ＋. 저장은 localStorage `hts-watchorders`.
   **주문은 나가지 않는다** — 감시 "정의"만 저장한다. 실제 주문은 KIS 연동 후 결정론적 코드가 낸다.
5. **관심그룹 선택 = 우측 시트 모달** — 드래그(≡)로 순서 변경, 하단 액션바에 추가/이름변경/삭제.

거부한 것: 이미지의 "옵션추가" 드롭다운. 동작 없는 선택지를 화면에 두면 전략이 실제보다
많은 걸 하는 것처럼 보인다(ADR-0009 취지 위배). 추격매수 안내 문구만 남겼다.

## 개정 2026-08-03 (2) — 검색바 수정 · 시각화 · 우측 드로어 (오너 지시)

1. **검색바 깨짐 = CSS 특이도 충돌.** `.omni input`(81행)과 `.hts input`(216행)이 같은 특이도(0,1,1)라
   뒤에 온 `.hts input` 이 알약 모양·아이콘 여백을 덮었다. `.hts .omni input`(0,2,1)으로 올려 해결.
   같은 이유로 깨져 있던 `.omni-pop button` 도 함께 수정. **앞쪽에 정의한 컴포넌트 규칙은
   `.hts` 를 붙여 넓은 규칙보다 특이도를 높인다** — 이 파일의 규칙으로 삼는다.
2. **한 글자마다 실시간 검색.** 디바운스 제거(서버가 메모리 위 종목마스터를 훑을 뿐). 대신 요청
   순번으로 늦은 응답이 최신 결과를 덮지 않게 막는다. 결과 행은 검색어 부분만 강조 + 코드·시장 서브라인,
   ↑↓/Enter 키보드 이동, 결과 없음 상태 표시.
3. **검색 정렬** — 이름에서 앞에서 맞을수록, 시총이 클수록 위. "삼성" → 삼성전자가 1등이라야 한다.
   (`/api/symbols` 가 `_latest_marcap()` 으로 정렬). 시장(KOSPI/KOSDAQ/KONEX)·종목유형 필터도 붙였다 —
   유형은 marcap 에 컬럼이 없어 이름 규칙으로 가른다(보통주·우선주·스팩·리츠). **ETF/ETN 은 marcap 에 아예 없다**(실측 0건).
4. **지수 보드** `/api/index-boards` — 코스피·코스닥 장중 5분봉(yfinance) + 전일종가 기준선 +
   투자자별 순매수(네이버 `/api/index/{code}/trend`). 순매수 단위는 네이버가 명시하지 않아
   거래대금과 대조해 **억원**으로 확정했다(코스피 거래대금 21.0조 대비 외국인 -25,547 → 억원이면
   -2.55조로 타당, 백만원이면 -255억으로 비현실적). 표시 전용 — 백테스트 신호로 쓰지 않는다.
5. **실시간 순위** `/api/ranking` — 상승률·하락률·거래대금·거래량·시가총액. marcap 최신 거래일 종가 기준이며
   **장중 실시간이 아니다**(화면에 "종가 기준" 명시).
6. **우측 종목 드로어** — 종목을 고르면 우측에서 밀려나온다(220ms). 요약(현재가·등락·30일 미니차트·
   거래량·거래대금·시총·종목뉴스) + [관심종목] [차트 크게 보기]. 상세는 차트 패널이, 요약은 드로어가 맡는다.
7. **홈 조회 실패를 감춘다** — `Promise.all` → `Promise.allSettled`. 하나가 실패해도 나머지를 그리고
   무엇이 실패했는지 표시한다(이전에는 조용히 빈 화면이 됐다 — "코스피가 안 보인다"의 한 원인).

거부한 것: 이미지의 "조회수 순위", "오늘 뜨는 국내 테마", "호가창", "시간별 수급" — 조회수·테마 분류·
호가·시간별 수급은 **데이터 자체가 없다**. marcap 일봉으로 만들 수 있는 순위(상승률·거래대금·거래량·시총)만 넣었다.

## 개정 2026-08-05 (3) — 첫 실행은 홈 탭 하나만 (오너 지시)

위 결정 4번(레이아웃 저장/복원)의 **기본 레이아웃**을 바꾼다. 기존 `defaultLayout` 은 홈·차트·
관심종목·전략·뉴스·재무·시장맵 7개를 한꺼번에 열어, 처음 켠 화면이 이미 꽉 차 있었다.
이제 홈 하나만 연다. 나머지는 메뉴에서 필요할 때 연다(클릭=이동/열기, Shift=새 탭 — 개정 1의 규칙 그대로).

**기본 레이아웃을 바꿀 때는 `LAYOUT_KEY` 를 올린다**(`hts-layout` → `hts-layout-v2`).
안 올리면 localStorage 에 저장된 옛 배치가 `fromJSON` 으로 먼저 복원돼 바뀐 기본값이 영원히 안 보인다.
대가로 기존 사용자의 배치가 한 번 초기화된다 — 기본 레이아웃 변경 시에만 올린다.
