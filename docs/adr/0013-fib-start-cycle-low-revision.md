# ADR-0013 개정안: 사이클이 끊겼다고 보는 기준 — 낙폭 + 지속 기간

- **상태:** 제안 (오너 확정 대기)
- **날짜:** 2026-08-07
- **관련:** ADR-0013(피보나치 시작점 = 사이클 저점), BORB-61
- **다음 세션 최우선.** 이 문서만 읽으면 이어서 할 수 있다.

## 왜 고치나

지금 기준은 **고점 대비 −50% 하락**이다(`web/src/hts/panels/strategyOne.ts` 의 `cycleDropPct: 50`).
오너 지적(2026-08-07): **−50% 는 임의로 낸 숫자였다.** 본질은 따로 있다 —

> "해당 종목의 모멘텀이 죽었을 때(미래 가치가 이제 안 보일 때, 약할 때), 세력이 떠났을 때.
> 이런 경우이면서 주가가 주르르륵 흐를 때야."
> "그게 아니라면 쭉 우상향하고 있겠지 중간에 큰 하락 없이"

즉 **사이클이 살아있는 구간 = 큰 하락 없이 우상향한 구간**이고, 시작점은 그 구간의 출발점이다.

−50% 가 실제로 내는 값(2026-08-07 실측):

| 종목 | −50% 가 잡는 시작점 | 오너 기대 |
|---|---|---|
| SK하이닉스 | 2023-01-03 · 73,100 (3년 반 전) | 27~30만 |
| 삼성전기 | 2026-07-30 · 865,000 (일주일 전) | — |
| 현대차 | 2020-03-20 · 65,000 (6년 전) | 20만 |

같은 규칙인데 3년 반 전 / 일주일 전 / 6년 전이 나온다. SK하이닉스는 73,100 에서 그으니
되돌림 선이 50%=153만, 78.6%=69만 으로 벌어져 **매수 목표가를 걸 수 없다**(화면에도
"매수 3차에 걸 지지/저항선이 없습니다" 가 뜬다).

## 실패한 후보들 (다시 시도하지 말 것)

| 후보 | 왜 안 되나 |
|---|---|
| 낙폭 임계값만 조정 (−15~−50%) | SK하이닉스가 −25%→−30% 사이에서 167만→15만 으로 건너뛴다. **27~30만이 나오는 값이 없다** |
| 최고가의 X% 컷 + 사이클 | SK하이닉스·삼성전자는 맞지만 **현대차가 445,000**(기대 20만). 상승 배수가 작은 종목에서 컷이 무의미해진다 |
| 이평선 마지막 이탈 | 현대차는 맞지만(240일선 204,500) **SK하이닉스가 162,700**(기대 27~30만). 급등 종목은 이평선이 따라 올라가 늦게 잡는다 |
| 이평선 값 자체 | SK하이닉스는 480일선조차 583,814 — 기대의 두 배 |
| 정답/현재가 비율 | 15.0%~47.1% 로 제각각. 단일 비율 불가 |
| 정답/최고가 비율 | 5.6%~25.5% 로 제각각 |

## 역산 — 오너가 찍어준 7개 정답

임계값을 지어내지 않기 위해, 오너가 차트에서 찍은 시작점들에서 역산했다.

정답: SK하이닉스 27~30만 · 삼성전자 5만 · 현대차 20만 · 로보티즈 3만 · 대원전선 4,500 ·
에스피지 3만 · 우리기술 1,700

각 시작점 이후 구간이 **실제로 견딘 하락**과, 그 직전에 있었던 **끊어야 할 하락**:

| 종목 | 찾은 시작점 | 견딘 하락 | 직전 하락(끊어야) |
|---|---|---|---|
| SK하이닉스 | 2025-06-18 · 245,000 | −27% (32일) | −42% (222일) |
| 삼성전자 | 2024-11-14 · 49,900 | −25% (38일) | −44% (83일) |
| 현대차 | 2025-04-11 · 175,800 | −35% (49일) | −41% (190일) |
| 로보티즈 | 2025-01-07 · 25,500 | −45% (65일) | −58% (239일) |
| 대원전선 | 2026-02-20 · 3,837 | −37% (38일) | −44% (191일) |
| 에스피지 | 2025-05-08 · 25,500 | −24% (63일) | −46% (62일) |
| 우리기술 | 2025-04-09 · 1,453 | −40% (80일) | −56% (174일) |

> 시작점은 "오너가 말한 가격 ±15% 안, 2024-08 이후" 로 자동 탐색한 값이다.
> **오너에게 날짜를 직접 확인받은 것이 아니다** — 이어서 할 때 먼저 확인할 것.

**낙폭 하나로는 안 갈린다**: 견딘 것 최대 −45%, 끊어야 할 것 최소 −41% 로 겹친다.
**기간 하나로도 안 갈린다**: 견딤 최장 80일, 끊음 최단 62일.

## 제안 (오너 확정 대기)

> **낙폭 −40% 이상이면서 60거래일 이상 끌면 사이클이 끊긴 것으로 본다.**

7개 중 6개가 맞는다. 두 값은 위 표에서 나온 것이지 지어낸 것이 아니다.

**안 맞는 하나:** 로보티즈가 견딘 −45%(65일)와 에스피지에서 끊어야 하는 −46%(62일)이
거의 같다. 가격과 기간만으로는 원리적으로 구분이 안 된다 — 여기서 갈리려면 오너가 말한
**"세력이 떠났나"(외국인·기관 수급)** 가 필요하다. 그 데이터는 아직 없다(BORB-33, 약 30시간).

표본이 7개라 더 찍으면 값이 달라질 수 있다.

## 이어서 할 일 (순서대로)

1. **오너에게 확인** — 위 "찾은 시작점"의 날짜가 실제로 의도한 지점이 맞는지. 가격만 듣고
   자동 탐색한 값이라 어긋났을 수 있다(첫 시도에서 삼성전자를 2018년, 현대차를 2014년으로 잡았다).
2. 확정되면 `find_cycle_low`(`src/layer3_strategy/surge.py`)에 **지속 기간 조건**을 넣는다.
   지금은 낙폭만 본다. 파라미터는 ADR-0009 대로 요청 데이터로 받는다 — 하드코딩 ❌.
3. `strategyOne.ts` 의 `cycleDropPct: 50` 교체. 화면 문구(`SimStep.tsx` "사이클 -N%")도 같이.
4. 세 종목 이상으로 화면 확인 — ③ 시뮬레이션에 종목 선택이 붙어 있다(커밋 `b385ce0`).
5. 회귀 테스트 — 기존 `test_strategy_core_regressions.py` 에 7개 정답을 케이스로 추가.

## 이 세션에서 확인만 하고 넘어간 것

- **수정주가는 문제없다.** SK하이닉스는 액면분할·병합이 아예 없어 수정주가=원본(배율 전부 1.0).
  삼성전기 최근 구간도 yfinance 와 일치(2026-07-30 저가 865,000 등). 2026년 7월 말 시장이
  크게 출렁여서(코스피 7-28 −10.8%, 7-31 +17.9%) 수정주가가 안 된 것처럼 보였을 수 있다.
- 현대차는 시작점(445,000)이 현재가(425,000)보다 높다 — 고점까지 갔다가 출발선 아래로
  되돌아온 상태. 이런 종목을 전략이 어떻게 다룰지는 아직 정의가 없다.
