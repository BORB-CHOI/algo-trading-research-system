# ADR-0018: 주문 창구 = 나무증권(NH PLUG), KIS 는 데이터용으로 병행

- **상태:** 수락 (조건부 — 모의투자 주문 왕복 검증 1건 남음, 아래 미해결 1번)
- **날짜:** 2026-08-15
- **관련:** ADR-0010(KIS 어댑터), ADR-0012(수급 소스), BORB-78, BORB-79
- **대체:** CLAUDE.md 의 "주문 창구 = KIS" 결정을 뒤집는다. ADR-0010 은 조회 전용으로 존속.

## 맥락 (Context)

NH투자증권이 2026-08-10 오픈API **PLUG**(나무 플러그 / N2 플러그)를 정식 출시했다.
오너 계좌가 나무증권이고, 수수료가 국내주식 0.01%(신규 24개월 무료)로 KIS 온라인
수수료(약 0.014%)보다 싸다. 오너 지시(2026-08-15): "KIS 에서 나무로 바꾸고, 둘 다
쓰는 구성도 검토하라."

출시 5일차 서비스라 추측 대신 실측으로 갈랐다. 앱키를 발급받아 운영 서버를 직접
호출한 결과(`scripts/namuh_probe.py`):

| 실측 항목 | 결과 |
|---|---|
| 일봉 | 넘김 조회로 1990년~ (한 호출 최대 5,000건) |
| 주봉/월봉 | 1990년~ / 1986년~ |
| 분봉 | 1~240분 전부. 굵을수록 깊다(1분 약 6주, 240분 약 6년) |
| 수급(일별) | 최대 999건 = 2022-07~. **날짜 지정 불가 — 더 과거는 못 받는다** |
| 호출 한도 | 실측 초당 약 7건 (문서 미기재) |
| 모의투자 | 있음(moapi, 계좌구분 03). 단 토큰은 운영 서버 전용, **영업일에만 주문 접수** |
| 계좌·잔고·체결내역 | 전부 조회됨 (`/n2/acctinfo` 로 계좌 자동 발견 — 계좌번호 설정 불요) |
| 수정주가 | 봉 데이터는 수정주가 (2018 삼성전자 분할 구간으로 확인) |
| 명세 함정 | openapi.json 의 `Output_0` 위치가 실응답과 다름 — **봉 배열은 `Output_1`** |

KIS 와의 차이 중 결정에 영향을 준 것:

- KIS 는 수급 이력이 1994-11 까지 나오고(추가 실측), 나무는 2022-07 이 바닥이다.
- KIS 모의투자는 전용 앱키로 완전 분리되지만, 나무는 운영 키 하나로 모의를 호출한다
  (주소 실수 = 실계좌 위험 → SDK 의 호스트 검증 + 스크립트에서 moapi 강제로 방어).
- 나무는 공식 파이썬 SDK(`nhplug`)·공식 MCP·llms.txt 를 제공한다. KIS 는 샘플코드 중심.
- 나무의 API 폭은 좁다(국내주식 31개). 조건검색·순위·업종 API 가 없다 —
  우리는 조건검색을 자체 계산(BORB-41)으로 가고 있어 영향 없음.

## 결정 (Decision)

**3층 구조로 역할을 나눈다. 어느 한쪽 전면 교체가 아니다.**

| 층 | 담당 | 근거 |
|---|---|---|
| **매매(주문·정정·취소·체결내역)** | **나무 PLUG** | 오너 계좌·수수료·공식 SDK |
| **앞으로의 시세 수집** (일·주·월·분봉 증분) | **나무 PLUG** | 한 호출 5,000건 — KIS 의 50배 |
| 과거 수급 백필 (1995~) | KIS (조회 전용, ADR-0012) | 나무는 2022 이전을 못 준다 |
| 백테스트 일봉 정본 | marcap (ADR-0002) | 상폐 종목 포함은 여기뿐 |

따라 나오는 결정:

1. **주·월봉 차트 정본 = 나무 수집본.** 일봉 합성(resample)은 상폐·미수집 종목,
   원주가 요청, 수집 이후 최신 꼬리에만 쓴다. (`api.main.period_candles`)
2. **봉 전량 수집**: 전 종목 × 일/주/월 + 분봉 9종을 `data/derived/namuh_bars/` 에
   parquet 으로 (`scripts/collect_namuh_bars.py`, 체크포인트 이어받기).
3. **수집 데이터는 저장소 밖.** KRX 원천 시세의 재배포 금지 관행 + 용량(수 GB) 때문에
   GitHub 업로드 금지, 로컬 `data/`(gitignore) 유지. 오너 확인 2026-08-15.
4. KIS 실전 키·어댑터(ADR-0010)는 **조회 전용으로 유지**한다. 폐기하지 않는다.
5. 실계좌 주문 실행은 사람이 스크립트로만(`scripts/namuh_buy_one.py`, 2중 확인).
   자동매매 경로의 주문 어댑터는 모의(moapi) 검증 후 별도 작업(BORB-78).

## 결과 (Consequences)

- `.env` 에 `NHPLUG_APP_KEY/SECRET/BASE_URL` 추가. 계좌번호는 넣지 않는다(API 로 발견).
- 의존성 `nhplug`(공식 SDK, MIT) 추가 — `pyproject.toml [namuh]`.
- 신생 서비스 리스크는 남는다: 문서에 한도 미기재(실측 의존), 장애 이력 없음,
  명세·실응답 불일치. 어댑터는 명세를 믿지 말고 실응답 기준으로 짠다.
- 모의 격리가 약한 만큼, 주문 코드는 **모의 서버 강제 + 계좌구분 검증**을 코드로 넣는다
  (`scripts/namuh_mock_order.py` 방식).
- 개발 규칙은 공식 템플릿(nhplug-sdk `templates/CLAUDE.md`)을 어댑터 작업 때
  프로젝트 참조 문서로 들여온다.

## 미해결 (Open questions)

1. **모의투자 주문 왕복 검증** — 2026-08-15 는 휴장일이라 "모의투자 영업일이 아닙니다"
   (14100). 다음 거래일 장중에 `scripts/namuh_mock_order.py` 실행. 통과가 이 ADR 의
   채택 조건이다. 실패하면 주문 창구 결정만 되돌리고 데이터 수집 결정은 유지한다.
2. Layer 4 주문 어댑터(나무) 구현과 KIS 어댑터와의 인터페이스 통일.
3. 공식 MCP(nhplug-mcp) 조회 전용 연결 — 연결 시 주문 도구를 settings deny 에 등록
   (CLAUDE.md 의 KIS MCP 규칙과 같은 방식).
4. PROJECT_GUIDELINES(§ 단계 5 "KIS 무료 모의투자" 등)의 본문 반영 — 다음 판 개정 때.
   그 전까지는 이 ADR 이 정본이다.
