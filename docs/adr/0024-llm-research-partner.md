# ADR-0024: LLM 은 부품이 아니라 리서치 파트너다 — 5단계로 다시 나눈다

- **상태:** 수락 (2026-09-11)
- **날짜:** 2026-09-10 (제안) · 2026-09-11 (5단계 개정·적용)
- **관련:** PROJECT_GUIDELINES §0.4 · §3.3 · §9.2 / ADR-0019(정체성) · ADR-0009(전략은 데이터)

## 맥락 (Context)

지침서 v4.0 은 LLM 을 **부품 하나**로 적어 뒀다. 옛 `layer2_llm_reading` 에서 뉴스·공시 글을
읽고 **등급(ordinal)만** 매기고, 그 등급이 전략 규칙의 입력이 되는 구조다.

여기에 코드 구조로 가드까지 걸어 뒀다. 옛 의존 방향이
`layer4_execution → layer3_strategy → layer2_llm_reading → layer1_data` 한 방향이라
**LLM 은 자기 위에 있는 통계·백테스트 결과를 아예 볼 수 없었다.**

**오너 지적 2026-09-10: 그건 기획과 다르다.** LLM 의 용도는 크게 둘이다.

| | 용도 |
|---|---|
| ① | 오너가 질문하면 원본 데이터와 통계를 참고해 **자유롭게 작업한 뒤 답한다** |
| ② | 특정 시점의 **국면 판단 + 통계값**을 묶어 **시나리오를 짠다** |

②에 들어가는 것: 상승/횡보/하락장, 수급주·세력주 구분, 시황, 투자심리, 주도테마, 모멘텀,
차트 모양새, 주도주, 매크로 지표, 공시, 뉴스.

### 금지선의 뜻을 다시 밝힌 것 (오너 2026-09-10)

> 매매를 하게 하지 말라 했지 매매 계획을 세우지 말라고 한 게 아니다. 그건 1·2단계 없이
> 아무런 정량적 지표도 없이 판단하게 하지 말라는 거였다. 이 매매 계획을 세우는 것조차도
> 백테스팅 검증을 통해 승률과 손익비 향상에 개선이 있는지 검증할 거다.

**금지선은 "계획을 세우느냐"가 아니라 "정량 근거가 있느냐"와 "주문을 내느냐"에 있다.**

### 이미 오너 뜻과 같던 조항

§9.2 의 "1단계(정량만) 성적과 2단계(+LLM) 성적을 따로 재서 견준다. LLM 을 넣어 실제로
나아졌는지 숫자로 보여야 한다" — 이것이 위 인용문의 "백테스팅 검증"과 같은 말이다.
뒤집는 게 아니라 **계획에도 그대로 적용하면 된다.**

## 검토한 선택지 (Options)

### A. 옛 번호를 뒤집는다 (통계를 2 로, LLM 을 3 으로)

- ❌ 옛 가드는 "LLM 이 사슬 아래에 있어서 위를 못 부른다"인데, LLM 을 올리면 **가드가 뒤집힌다.**
  실행이 LLM 위에 놓여 LLM → 실행 경로가 구조로 열린다.
- 가드레일 위반: 있음.

### B. 자리는 그대로 두고 LLM 에 통계 읽기 권한만 준다

- ❌ 의존 방향이 양방향이 된다. "한 방향" 규칙이 깨지면 나중에 LLM 이 실행을 부르는 것도
  막을 근거가 없어진다.
- 가드레일 위반: 있음.

### C. LLM 을 매매 파이프라인 밖으로 뺀다 (`src/research/`)

- 2026-09-11 폐기. A·B·C 는 전부 "옛 4단 구조를 어떻게 비틀까"였다. 번호를 안 건드리려고
  옆길로 돌아간 것이다.

### D. 번호를 매기는 기준 자체를 바꾼다 — 5단계 (채택)

옛 번호는 **매매가 흘러가는 차례**(데이터 → 글 해석 → 전략 → 체결)였다. 그 차례에서는
통계가 맨 끝이고 LLM 이 그보다 앞이라, "통계를 보고 시나리오를 짠다"가 성립하지 않는다.

새 번호는 **일하는 차례**다. 오너가 정한 다섯 단계를 그대로 쓴다.

## 결정 (Decision)

### 1. LLM 용도는 둘이다 (오너 결정 2026-09-10)

**용도 ① 물어보면 답하는 리서치.** 1·3단계 원본과 2단계 통계를 참고해 필요한 작업을 하고
답한다. 일회용 코드를 짜서 돌려도 되고 데이터를 써도 된다. 결과물은 글과 표다.

오너가 든 예시:

> "외국인 매수세가 연속되거나 일정 금액을 넘었을 때, 며칠 뒤 가격에 얼마나 영향을 주나?"

**임계값(며칠 · 얼마)은 질문에 담겨 오거나 오너가 화면에서 고른다. LLM 이 고르지 않는다.**

**용도 ② 시나리오 구상.** 특정 시점의 국면을 읽고 그 시점까지의 통계와 묶어 매매 시나리오를
짠다. 결과물은 파일로 남는 계획서다.

### 2. 경계

| | 되나 |
|---|---|
| 정량 데이터·통계를 보고 매매 계획을 세운다 | ⭕ |
| 그 계획을 백테스트에 올려 검증한다 | ⭕ **필수** |
| 정량 근거 없이 글만 읽고 판단한다 | ❌ 이것이 원래 금지였던 것 |
| LLM 이 주문을 낸다 (전송·정정·취소) | ❌ 그대로 금지 |

### 3. LLM 이 세운 계획도 백테스트를 통과해야 한다

- 정량만 돌린 성적과 LLM 계획을 넣은 성적을 **따로 재서 견준다**
- **승률과 손익비가 실제로 나아졌는지 숫자로 보인다**
- 안 나아지면 그 계획은 안 쓴다
- LLM 쓴 돈도 비용에 넣는다

### 4. 5단계 (오너 결정 2026-09-11)

| 단계 | 무엇 | 폴더 | 줄 |
|---|---|---|---|
| 1 | **정량 데이터 모으기** — 거래소·증권사가 주는 확정된 숫자 | `layer1_market_data/` | 6,295 |
| 2 | **통계** — 전략 규칙 + 백테스트로 승률·손익비 | `layer2_backtest/` | 7,235 |
| 3 | **주관적 데이터 모으기** — 사람이 한 말 | `layer3_text_data/` | 적음 |
| 4 | **LLM** — 글과 통계를 읽고 해석·시나리오 | `layer4_llm_reading/` | **비어 있음** |
| 5 | **시나리오 제안 → 승인 → 예약 주문** | `layer5_execution/` | **비어 있음** |

**5단계는 주문 보내기가 아니다** (오너 지적 2026-09-11). 안에 들어가는 것:

- 시나리오를 사람이 볼 수 있게 화면에 보여주기
- 사람이 승인하거나 거절
- 승인된 것만 예약 매수·매도 주문으로 바꾸기
- 실제 매매까지 이어붙이기

그래서 **5단계는 화면과 같이 만들어야 한다.** 뒤쪽 코드만으로는 성립하지 않는다.

### 5. 주관적 데이터(3)를 정량 데이터(1)에서 갈라 놓는다

숫자와 글은 모으는 방법도 믿는 정도도 다르다. 1단계는 거래소·증권사가 주는 확정된 숫자고,
3단계는 사람이 한 말이다. 이것으로 "뉴스·자막 원본을 어디에 둬야 하나"가 정리된다.

**업종과 테마는 갈라 둔다** (오너 2026-09-11).

| | 어디 | 왜 |
|---|---|---|
| 업종 분류 (`industry.py`) | 1단계 | 고정 분류다. 숫자로 다룰 수 있다 |
| 테마 분류 (`themes.py`) | 3단계 | 시황에 따라 생겼다 사라진다. 오너 예: "앤트로픽 상장 관련주"는 기존 정량 분류로 안 잡힌다 — 뉴스 해석이 들어가야 한다 |

### 6. 부르는 방향과 끊어 둔 곳

큰 번호가 작은 번호를 부른다. 작은 쪽이 큰 쪽을 부르지 않는다.

**4단계는 5단계를 부를 수 없다.** LLM 은 시나리오를 글로 낼 뿐이고, 주문으로 바뀌는 것은
사람이 승인한 뒤 5단계가 한다. 옛 가드("LLM 이 사슬 아래에 있어서 실행을 못 부른다")를
이 자리로 옮긴 것이다. **시험으로 막는다.**

### 7. 고칠 문구

| 어디 | 전 | 후 |
|---|---|---|
| §9.2 | LLM 출력은 등급까지만. 확률·목표가 ❌ | 계획까지 낼 수 있다. 단 **정량 입력 필수**, 백테스트 통과해야 쓴다 |
| §0.4 | AI 는 BUY/SELL·비중·손절선을 정하지 않는다 | AI 는 **정량 근거 없이** 정하지 않는다. **주문은 어떤 경우에도 AI 가 내지 않는다** |

**정량값은 전부 임시값이다.** 어떤 통계를 시나리오 입력으로 넣을지, 개선 판정 기준을 얼마로
볼지는 오너가 화면에서 정한다(ADR-0009 · §0.4).

## 결과 (Consequences)

### 실제로 옮긴 것 (2026-09-11)

| 옛 이름 | 새 이름 |
|---|---|
| `layer1_data` | `layer1_market_data` |
| `layer1_data/news.py` · `themes.py` | `layer3_text_data/` |
| `layer3_strategy` (15개 파일) | `layer2_backtest` |
| `layer4_execution` 의 백테스트 8개 파일 | `layer2_backtest` |
| `layer4_execution/brokers/` | `layer1_market_data/brokers/` |
| `layer2_llm_reading` | `layer4_llm_reading` |
| (없음) | `layer5_execution` — 새로 만듦, 비어 있음 |

**`brokers/` 가 1단계로 간 이유:** 이름은 "주문 창구"인데 실제로 쓰는 곳 11군데가 전부
데이터를 받아오는 스크립트였다(`backfill_kis_supply` · `collect_kis_members` ·
`update_data` 등). **주문 코드는 하나도 없었다.** 그래서 5단계는 지금 완전히 비어 있다.

실측: 파일 90개에서 이름을 고쳤고, 모듈 69개가 전부 불러와지고, 시험 59개가 전부 수집됐다.
폴더 이동은 `git mv` 로 해서 이력이 따라온다.

### 안 고친 것

`docs/project/CHANGELOG.md` 는 날짜별 기록이라 옛 이름을 그대로 뒀다. 바꾸면 그때의 기록이
아니게 된다. 대신 `ARCHITECTURE.md` 에 옛 이름 → 새 이름 표를 넣어 찾을 수 있게 했다.

### 감수하는 위험 — 미래 데이터 훔쳐보기

가격 데이터는 날짜를 자르면 되는데 **LLM 은 그 뒤에 무슨 일이 있었는지 이미 알고 있다.**
2023년 시점 계획을 세우라고 시켜도 모델은 결과를 안다. 종목명·날짜·특징적 수치를 가려도
"시총 이 정도 + 이 업종 + 이 시기"는 알아본다. **완전히 못 막는다.**

**오너 결정: 이 문제는 4단계를 실제로 만들 때 다룬다.** 지금 막지 않는다.

### 재현성

LLM 은 같은 입력에도 다른 답을 낸다. §4.6 "같은 입력 → 같은 출력"을 지키려면 **계획과 그
입력을 파일로 남겨야** 되살릴 수 있다.

## 검색만으로는 "과거에 이랬으니 이번에도"를 못 한다 (오너 지적 2026-09-10)

글을 찾아주는 것과 세는 것은 다른 일이다.

| 하고 싶은 말 | 있어야 하는 것 | 검색만으로 되나 |
|---|---|---|
| "2023년에 이 종목 무슨 얘기가 있었나" | 찾기 | ⭕ |
| "이런 재료가 나온 게 과거 137번, 그중 82번 올랐다" | 세기 | ❌ |
| "그러니 이번에도 오를 가능성이 크다" | 세기 + 그 뒤 주가 붙이기 | ❌ |

**세려면 글 하나가 한 줄짜리 기록이 되어야 한다.** 날짜 · 종목 · 무슨 재료 · 얼마나 센가.
여기까지 되면 그 뒤 주가는 이미 갖고 있으므로 5일 뒤·20일 뒤 수익률을 붙일 수 있고,
그때부터 2단계 백테스트가 수급 데이터와 똑같이 다룰 수 있다.

이 단계는 원래 문서에 있었다 — `hypotheses/news.md` 의 재료 다섯 갈래(r1~r5)와
§9.2 의 "등급(ordinal)" 이 정확히 이것이다. **검색(RAG)은 그 줄을 만들 때 비슷한 과거
사례를 빨리 찾는 도구이지, 그 자체가 목표가 아니다.**

## 미해결 — 오너 답 (2026-09-10)

| # | 물었던 것 | 답 |
|---|---|---|
| 1 | 미래 데이터 훔쳐보기를 어디까지 막나 | **뒤로 미룬다.** 4단계를 실제로 만들 때 다룬다 |
| 2 | 계획을 어떤 서식으로 내나 | **일단 통계부터 내 본다.** 서식은 그다음 |
| 3 | Graph RAG · 지식그래프 · Vector RAG 를 쓰나 | **쓸 것 같다고 보되 확정은 아니다.** 크롤링·API 부터 만들어 데이터를 본 뒤 구조를 정한다 |
| 4 | "자유롭게 작업"이 어디까지인가 | **일회용 코드를 짜서 돌려도 되고, 데이터를 써도 된다** |
| 5 | 여러 사람이 같이 쓰나 | **오너 혼자 쓴다.** 다만 개발은 나눠 맡길 수 있다 |

### 남은 것

1. **4단계가 5단계를 부르지 못하게 하는 시험**을 아직 안 만들었다. 지금은 5단계가 비어
   있어 부를 것도 없지만, 5단계를 만들 때 같이 넣어야 한다.
2. 3단계 수집(뉴스·시황·자막)은 **뒤로 미뤘다** (오너 2026-09-10 — 통계가 먼저).
