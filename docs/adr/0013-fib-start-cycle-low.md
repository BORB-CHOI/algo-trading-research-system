# ADR-0013: 피보나치 시작점 = 상승장 사이클 저점

- **상태:** 수락 (구현 완료 — `surge.find_cycle_low` / `/api/simulate` / ③ 시뮬레이션)
- **날짜:** 2026-08-06
- **관련:** ADR-0011(급등 앵커와 분할), ADR-0009(전략은 데이터)
- **대체:** ADR-0011 의 **피보나치 시작점** 정의(급등 시작일 시가)를 이 문서가 대신한다.
  급등 앵커 자체는 그대로 남는다 — 파동 식별·앵커 VWAP·손절 기준(급등 시작가) 용도.

## 맥락 (Context)

③ 시뮬레이션 차트를 처음 본 오너가 지적했다 — "피보나치 시작점이 내가 평소에 긋는 것과
다르게 더 짧게 그어져 있다." 오너가 실제로 긋는 방식:

> 상승장 사이클이 시작되기 직전. -50%? -60%? 하락을 안 맞은 구간은 전부 상승장으로 봄.

급등 시작일 시가(ADR-0011)는 파동의 마지막 급등 구간만 잡는다. 오너는 그보다 훨씬 아래,
큰 하락이 끝난 바닥에서 파동 전체에 긋는다. 시작점이 위에 있으면 구간이 짧아지고 되돌림
매수가가 전부 위로 밀린다 — 비싸게 사는 쪽으로 틀린다.

## 결정 (Decision)

### `surge.find_cycle_low(df, *, drop_pct, as_of=None)` — 지그재그 상태기계 (대칭 임계값)

- 상승 상태: 고점(최고 High)을 갱신하다가 고점 대비 `drop_pct` % 이상 빠지면 하락 상태로.
- 하락 상태: 저점(최저 Low)을 갱신하다가 저점 대비 `drop_pct` % 이상 반등하면 그 저점을
  **사이클 시작으로 확정**하고 상승 상태로.
- 데이터 끝이 하락 상태면 그때까지의 최저 Low(진행 중 바닥)를 쓴다. 사이클이 여러 번이면
  가장 최근 확정 저점. 동률은 가장 이른 날(strict 비교). 하락·반등 판정은 경계 포함(이상).
- `drop_pct` 하락이 한 번도 없으면 구간 최저 Low + `confirmed=False` — 화면이 "기준
  미충족"을 표시한다.
- 오너도 -50 이냐 -60 이냐를 확정하지 않았다 → **기본값 없음**(ADR-0009). 화면 파라미터
  `사이클 하락 기준(%)`, 예시값 50. 전략에 저장된다(`cycleDropPct`).

### `/api/simulate` 조립

- **전체 이력을 읽는다** — 사이클 저점은 수년 전 바닥일 수 있다. 급등 탐색·체결 스캔은
  기존 2년 창을 유지한다(전체 이력을 주면 수년 전 파동이 급등으로 잡힌다).
- 사이클 저점은 **파동 고점일까지만** 보고 찾는다 — look-ahead 방지 + 시작점이 고점 뒤에
  잡히는 것 차단.
- **피보 구간 = 사이클 저점 → 파동 고점.** 분할 매수 레벨(`buy_levels`)·되돌림 원값 선
  모두 이 구간에서 계산한다.
- 손절 기준선(support)에 `cycle_low`(사이클 저점) 추가 — 피보 100% 이탈 손절용.

### 같은 날 UI 결정 (오너 지시)

- ③ 차트 **요소별 표시 필터** — 앵커/피보나치/매수/매도/손절/VWAP/체결 칩. 데이터
  재적재 없이 다시 그려 줌이 유지된다(window resize → `chart.resize()` 경로).
- 수평선 라벨은 선 **아래**에 그린다 — 위에 얹으면 윗선·윗라벨과 포개져 숫자가 안 읽힌다.

## 결과 (Consequences)

- 되돌림 레벨이 크게 내려간다 — 매수가가 싸지고 체결이 덜 되는 보수적 방향.
- `drop_pct` 에 따라 사이클이 수십 년 전까지 간다. 실측(삼성전자, 2026-08-05 기준):
  -30% → 2026-07 바닥, -60% → 2000-10 닷컴 붕괴 바닥. **임계값이 곧 전략이다** —
  화면에서 조정하고, 채택은 백테스트(ADR-0007)로 검증한다.
- KRX 상하한가 ±30% 에서는 `drop_pct ≥ 47` 이면 한 봉 안에서 하락 확정이 자기 고가
  기준으로 걸릴 수 없다(저가/고가 ≥ 0.7/1.3). 같은 봉에서 신저가와 반등 확정이 동시에
  나오면 그 봉의 저가가 저점이다 — 장중 순서를 모르니 봉 하나는 쪼개지 않는다.

## 검증 (Verification)

`tests/test_surge.py::TestFindCycleLow` 9건 — V자 바닥 / 반등 미확정(진행 중 바닥) /
하락 없음(confirmed=False) / 복수 사이클(고점 재측정) / as_of 재현 / 저가 동률 /
경계값(정확히 ±50%) / drop_pct 범위 / 기본값 없음. 전체 377개 통과.

## 미해결 (Open questions)

1. 매도 반등률 기준점(`anchor_high` 등)·앵커 VWAP 은 여전히 급등 앵커 기준이다. 피보
   구간이 커진 만큼 조합이 어색해지는 케이스는 오너가 차트로 확인한다.
2. 반복 매매(매도 후 재매수) 시뮬레이션은 별도 작업 — 백테스트 엔진 확장(ADR-0007 개정)
   때 회차 루프와 함께 넣는다.
