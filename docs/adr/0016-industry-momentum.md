# ADR-0016: 업종/산업 모멘텀 — 종목이 속한 무리가 같이 오르는가

- **상태:** 제안
- **날짜:** 2026-08-07
- **관련:** ADR-0002(데이터 소스), ADR-0009(전략은 데이터), ADR-0010(KIS 어댑터), ADR-0013(사이클 저점)

## 맥락 (Context)

오너 요구(2026-08-07): 전략 1호 종목 선정에서 **개별 종목만 볼 게 아니라, 그 종목이 속한
무리 자체에 그 시점 모멘텀이 있는지**까지 추려야 한다. "테마군의 절반 이상이 상승세"가
원래 표현이다.

계산 자체는 산술이다 — 무리 구성원의 등락을 세면 된다. LLM 은 필요 없고, 넣어서도 안 된다
(PROJECT_GUIDELINES §3.2 — LLM 은 ordinal 등급까지, 매매 판단은 결정론적 코드).
**진짜 문제는 데이터다: 각 시점에 그 무리가 누구였는지를 알아야 한다.**

기존 `src/layer1_data/themes.py`(네이버 m.stock 테마)는 쓸 수 없다. 코드 주석에도
"백테스트·매매 판단에 쓰지 않는다 — point-in-time 아님"이라 박아뒀다. 이 API 는 **오늘 명부만**
준다. 2023년 구간에 오늘 명부를 쓰면, 지금 그 테마로 묶인 종목은 **테마가 뜬 뒤 편입된**
종목들이라 결과를 알고 명부를 짠 셈이 된다(look-ahead). 테마 자체도 생겼다 사라진다.

## 실측 (2026-08-07)

`scripts/kis_probe_industry.py` — 실전 키, 조회 전용.

### KIS 에 테마는 없다

국내주식 API 156 개 전수 확인. 테마 관련 엔드포인트 **0 건**. KIS 가 주는 것은 거래소 표준
**업종**이다. 네이버의 "2차전지·초전도체" 같은 테마와는 다른 물건 — 업종은 고정 분류,
테마는 시장이 만들어내는 유행이다.

### 업종 일자별지수 — TR `FHPUP02120000`

| 확인한 것 | 결과 |
|---|---|
| 과거 이력 | 요청일 `20170102` → `20160808~20170102` 응답. **백테스트 구간 2017~ 을 덮는다** |
| 한 호출 분량 | **100 거래일** (수급 API 30 거래일보다 낫다) |
| point-in-time | `FID_INPUT_DATE_1` 날짜 지정 호출 — **재현 가능** |
| 업종 수 | 138 개 (코스피 세부 + 코스닥). `FHPUP02140000` 으로 코드 목록 획득 |
| 정확도 | 코스피 종합을 yfinance `^KS11` 과 대조 — **소수점까지 일치** |

정확도 대조를 남기는 이유: output2 의 2026-07-31 등락률이 **+17.91%** 로 찍혀 처음엔 깨진 값을
의심했다. 실제로는 그 구간에 폭락·급반등이 있었고 두 독립 소스가 일치했다. 과거 변동폭 감각으로
데이터를 의심하면 안 된다는 기록으로 남긴다.

### 상승/하락 종목 수는 과거를 못 받는다

`ascn_issu_cnt`(상승 종목 수)·`down_issu_cnt`(하락 종목 수)는 **`output1`(오늘 요약)에만** 온다.
일자별인 `output2` 에는 지수 OHLC·등락률·거래량·20일 이격도만 있다.

→ 오너 표현 그대로의 "절반 이상 상승"을 **과거 구간에는 이 API 로 만들 수 없다.**

### 종목 → 무리 매핑 (TR `CTPF1002R` 주식기본조회)

| 필드 | 생존 종목 | 상폐 종목 |
|---|---|---|
| `idx_bztp_mcls_cd` (**지수 업종** — 업종 지수와 연결되는 코드) | 013 전기,전자 | **없음** |
| `std_idst_clsf_cd` (**표준산업분류**) | 032601 반도체 제조업 | **있음** |

상폐 종목도 조회 자체는 된다. 다만 지수 업종 코드는 "지금 어느 업종 지수에 편입돼 있나"라서
상장폐지되면 사라지고, 회사의 사업 분류인 표준산업분류만 남는다.

**자릿수 함정** — 종목 필드는 `013`(3자리)로 오는데 일자별지수 API 는 `0013`(4자리)만 받는다.
`013` 으로 부르면 실패가 아니라 **빈 응답**(지수 0.00, 0행)이 온다. 조용히 비는 쪽이라 더
위험하다. marcap 종목코드 `zfill(6)` 과 같은 성격 — 매핑 시 `zfill(4)` 로 보정한다.
실측: `0013` → 지수 95,052.64 · 상승 29 / 하락 51 · 일자별 100행.

표본 주의: 처음 뽑은 상폐 4건이 전부 리츠·스팩이었다. 이들은 살아 있어도 업종 분류가 없을 수
있어 판단 근거가 안 된다. 스팩을 걸러 일반 종목(에이트원·창대정밀·디딤이앤에프 등 6건)으로
다시 확인한 결과다.

### 두 분류의 트레이드오프

| 종목 | 표준산업분류 | 지수 업종 |
|---|---|---|
| SK하이닉스 | 032601 반도체 제조업 ✓ | 013 전기,전자 |
| 삼성전자 | 032604 **통신 및 방송 장비 제조업** ✗ | 013 전기,전자 |

표준산업분류는 세분화돼 있지만 **대표 사업 하나만** 찍어서 실상과 어긋날 수 있다.
지수 업종은 뭉뚱그려도 시장이 실제로 인식하는 무리에 가깝다.

## 검토한 선택지 (Options)

### A. KIS 업종 지수만

간단하고 거래소 공식 분류를 그대로 쓴다. 문제는 **상폐 종목에 지수 업종 코드가 없다**는 것.
그 종목들이 업종 조건에서 통째로 빠지면 CLAUDE.md 가 금지한 생존 편향이 업종 조건에만 생긴다.
"절반 이상 상승"도 과거 구간에는 못 만들어 지수 등락률로 대체해야 한다.

### B. 표준산업분류로 묶고 marcap 으로 직접 센다

상폐 종목도 분류가 있으니 무리에 포함된다. 각 시점의 "무리 중 몇 %가 올랐나"를 marcap
가격으로 직접 계산하면 오너 표현 그대로, 과거 구간까지 정확히 구현된다. point-in-time 완벽.
문제는 계산이 틀려도 비교할 기준이 없다는 것.

### C. B 로 계산하고 A 로 대조

## 결정 (Decision)

**C 를 채택한다** (오너 결정 2026-08-07).

- **무리의 정의** — 살아있는 종목은 **지수 업종**(`idx_bztp_mcls_cd`), 상폐 종목은 지수 업종이
  없으므로 **표준산업분류**(`std_idst_clsf_cd`)로 메꾼다. 두 체계를 잇는 **매핑표**가 필요하고,
  이것이 이 결정의 실제 작업량이다.
- **무리 모멘텀** — 각 시점, 그 무리 구성원 중 상승 종목 비율을 marcap 가격으로 직접 계산한다.
  상폐 종목이 그 시점에 살아 있었다면 분모·분자에 모두 포함된다.
- **대조** — KIS 업종 일자별지수(2017~)를 받아 자체 계산이 지수 등락과 어긋나지 않는지 검산한다.
  대조용이지 신호원이 아니다.
- **임계값** — "절반 이상"의 50%, 관측 창 길이는 전부 placeholder. 하드코딩하지 않고 ADR-0009
  대로 요청 데이터로만 받는다.

**재무는 무리를 나누는 데 쓰지 않는다.** 매출액·영업이익 같은 숫자로는 업종을 판별할 수 없고,
분류는 이미 주어져 있다. 재무는 종목 자체의 품질 필터(별개 조건)로만 쓴다.

## 결과 (Consequences)

- 네이버 테마(`themes.py`)·업종(`industry.py`)은 **화면 표시 전용으로 유지**한다. 백테스트 경로에
  들어가지 않는다는 기존 주석을 그대로 지킨다.
- KIS 업종 지수 백필 비용: 138 업종 × (2017~현재 약 2,350 거래일 ÷ 100) ≈ **약 3,300 호출**.
  수급 백필(22만 호출)에 비하면 무시할 수준이다. 스로틀은 여전히 필요하다(`EGW00201`).
- 상승/하락 종목 수(`output1`)를 **오늘부터 매일 쌓아두면** 앞으로의 구간에서는 KIS 집계값과
  자체 계산을 직접 대조할 수 있다. 안 쌓으면 1년 뒤에도 대조 기준이 없다.

## 미해결 (Open questions)

1. **분류 매핑이 오늘 기준이다.** 과거에 그 회사가 다른 업종이었는지 KIS 는 알려주지 않는다.
   산업분류 변경은 테마와 달리 드물어 테마 명부만큼 심각하지는 않지만, 편입·변경이 잦은
   구간(지주사 전환, 사업 매각)에서 얼마나 어긋나는지는 측정한 적 없다.
2. 지수 업종(중분류 24종 수준) ↔ 표준산업분류(6자리 세분류)를 **어느 입도로 맞출 것인가.**
   너무 굵으면 무리가 커져 모멘텀이 희석되고, 너무 잘면 구성원이 몇 개 안 남아 비율이 요동친다.
3. 무리 구성원이 N 개 미만일 때 비율을 신뢰할 수 있는가 (방법론 가드레일의 N<30 과 같은 문제).
4. 상승 판정 기준 — 당일 등락률 양수인가, 최근 N 일 수익률인가. 전략 1호의 사이클 정의
   (ADR-0013)와 맞춰야 한다.
