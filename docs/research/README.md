# 연구 문서 안내

연구 문서는 **확인 전**과 **확인 후**를 분리한다.

| 단계 | 위치 | 내용 |
|---|---|---|
| 확인 전 | [hypotheses/](hypotheses/README.md) | 트레이더 발언·직관·학술 통설과 필요한 데이터 |
| 확인 후 | [FINDINGS.md](FINDINGS.md) | 정의·표본·구간·세부 집단·불확실성을 포함한 분석 결과 |

## 작업 흐름

1. 오너가 [가설 목록](hypotheses/README.md)에서 확인할 주장과 조건·임계값·구간을 고른다.
2. AI는 [확정 원칙](../foundation/PROJECT_GUIDELINES.md)의 방법론에 따라 데이터를 계산한다.
3. 전체 평균뿐 아니라 사전에 고른 시기·거래대금·시총·시장 국면 등의 차이를 확인한다.
4. 실행 명령과 상세 산출물을 남기고 [검증 결과](FINDINGS.md)에 요약한다.
5. 같은 구간을 보며 정의를 바꿨다면 탐색 결과로 표시하고 별도 구간에서 다시 확인한다.

가설 파일에는 결과를 쓰지 않는다. 결과 때문에 가설 원문과 출처가 조용히 바뀌는 일을 막기
위해서다. 반대로 `FINDINGS.md`에는 근거 없는 후보를 추가하지 않는다.
