# 피보나치 파동 정답지 후보

파동 바닥을 눈으로 정리할 때 비슷한 급등주만 반복해서 고르지 않도록 만든 1차 후보 목록이다.
테마는 표본을 다양하게 나누기 위한 분류일 뿐이며 당시 시점의 종목 선정 조건으로 사용하지 않는다.

- 총 38개 사례
- 코스피 20개 / 코스닥 18개
- 정상 상장 30개 / 상장폐지 8개
- 시총은 초소형주부터 초대형주까지 포함
- 영풍은 서로 다른 흐름을 비교하기 위해 2022년·2024년·2025년을 별도 사례로 분리
