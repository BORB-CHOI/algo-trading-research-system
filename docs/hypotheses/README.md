# 조건 원재료 목록

여기 있는 것은 **오너가 화면에서 조건을 만들 때 꺼내 쓰는 원재료**다.
고수의 발언이든 오너의 직관이든 학술 논문이든, 데이터로 확인하기 전까지는 같은 등급이다.

**이 폴더는 검증 계획이 아니다.** 무엇을 먼저 볼지, 어떻게 조합할지는 오너가 화면에서 정한다.
실제 분석 정의와 결과는 [`../research-findings.md`](../research-findings.md)에 따로 누적한다.

## 왜 따로 두는가

지침서(`../PROJECT_GUIDELINES.md`)는 **확정된 원칙**만 담는다. 확인 안 된 주장이 원칙과 같은
문서에 섞이면, 시간이 지나면서 "우리가 정한 규칙"처럼 읽히게 된다. v3.8에서 실제로 그렇게
됐다 — 후보 35개가 "조건 라이브러리"라는 이름으로 확정 도구처럼 적혀 있었다.

## 항목 서식

### (한 줄 제목)

- **출처 발언:** 누가 언제 무슨 말을 했나 (원문 인용)
- **쉬운 말:** 무슨 뜻인지 중학생도 알아듣게
- **전략 계층:** 종목 선정 / 시장 상황 / 전략군 / 모양 / 진입 / 비중 / 청산 / 위험 / 실행
- **필요 데이터:** 무엇이 있어야 하나 + 지금 있나
- **화면에서 고를 수 있나:** ⭕ (조건 이름) / ❌ (아직 없음 — 만들어야 함)
- **주의:** 그때 알 수 있었던 정보만 쓰려면 무엇을 조심해야 하나

**넣지 않는 것: 우선순위 · 검증 상태 · 번호 · 실험 조합표.**
무엇을 먼저 볼지, 어떻게 조합할지는 **오너가 화면에서 정한다.**

임계값(숫자)은 전부 **임시값**이다. v3.8이 적어 둔 숫자는 "그때 그렇게 추정했다"는 기록이지
정답이 아니다.

## 데이터로 확인할 때 지킬 것

지침서 §4에 있는 것과 같다. 여기 다시 적는 이유는 원재료를 꺼내 쓸 때 바로 옆에 있어야
하기 때문이다.

- **그때 알 수 있었던 정보만.** 오늘 시총으로 과거 종목을 고르면 안 된다.
- **표본이 적으면 믿지 않는다.** 30건 미만은 우연과 구분이 안 된다.
- **합쳐서 좋아졌다고 채택하지 않는다.** 조건을 **하나씩 빼 보고** 그게 없을 때 얼마나
  나빠지는지를 본다. 안 나빠지면 그 조건은 값을 못 하고 있는 것이다.
- **승률과 순위 상관(IC)은 다른 지표다.** 둘 다 본다.
- **거래비용과 슬리피지를 처음부터 넣는다.** 빼고 재면 다 좋아 보인다.
